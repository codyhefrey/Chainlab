# Chainlab — record integrity prototype release gate

**Status:** Local linked SHA-256 record chain; not a decentralized blockchain.

## Automatically verifiable
- Synthetic records generate hash-linked blocks and a terminal checkpoint.
- CLI verifies a separately saved checkpoint, rejects modified records and rewritten histories.

## Blocking launch work
- Independently trustworthy checkpoint storage and authentication; signed writers and durable auditable records.
- Threat model, network consensus and peer security before claiming decentralization.
- Governance, privacy/retention constraints, disaster recovery and operational measurements.
- No smart contracts, native currency, gas payments or real network validated.

A hash-chain check alone does not establish the truth of a record.
