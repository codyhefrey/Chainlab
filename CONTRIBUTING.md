# Contributing to Chainlab

Please open an issue before major changes. Fork the repository, create a focused branch, add tests, and submit a pull request for maintainer review.

Run the existing Python test suite before requesting review. Do not commit secrets, private data, enterprise code, or third-party intellectual property. Use synthetic examples. Report vulnerabilities privately to maintainers.

Community contributions are limited to this public repository. Maintainers decide whether to accept changes. Passing CI and receiving a review should be required by branch protection before merging.
